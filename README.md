# AM Soul Mate - Luxury Herbal & Ayurvedic Beauty Care

A high-performance e-commerce and catalog web application for **AM Soul Mate (Partner of Healthy Life)**, featuring handcrafted herbal remedies, Ayurvedic skincare, hair growth treatments, and artisanal soaps with direct 1-click WhatsApp order generation.

---

## 🌿 Features

- **Luxury Brand Aesthetic:** Emerald & gold palette tailored for premium organic herbal beauty.
- **Official AM Soul Mate Logo:** Integrated across the header, footer, and brand storytelling sections.
- **Direct WhatsApp Ordering:** Seamless 1-click checkout and inquiry forwarding to WhatsApp helpline **`+94 75 677 1358`**.
- **Interactive Product Catalog:** 22 Ayurvedic formulations across 6 categories (Skincare, Hair Care, Artisan Soaps, Body Care, Glow Combos).
- **Cart & Free Islandwide Delivery Calculator:** Auto-calculates subtotal and triggers free delivery above LKR 4,000.
- **Quick-View Modal:** Detailed breakdown of ingredients, herbal benefits, and usage instructions for each item.
- **Responsive & Mobile-First:** Fluid layouts optimized for smartphones, tablets, and desktops.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/leed56/Soul.git

# Enter the directory
cd Soul

# Install dependencies
npm install
```

### Development
```bash
# Start local development server
npm run dev
```
Visit `http://localhost:5173` in your browser.

### Build
```bash
# Build for production
npm run build
```
